# AMGR_Engine ⚙️

**AMGR_Engine** — это кастомный игровой движок, разрабатываемый с нуля на **C++20** и **Vulkan API**. 

Движок создается специально для проекта **NELLA** — сюжетной изометрической action-adventure игры в сеттинге студенческого общежития. Движок заточен под рендер стилизованной low-poly графики, ритм-боевки и глитч-интерфейсов в стиле мессенджеров (WhatsApp-style UI).

## 🛠 Технологический стек
* **Язык:** C++20
* **Графический API:** Vulkan
* **Оконная система и ввод:** GLFW
* **Архитектура:** EnTT (Entity-Component-System)
* **Сборка:** CMake / MinGW

## 🚀 Текущий прогресс (Vulkan Core)
Фундамент графического API успешно заложен. Движок корректно общается с GPU (тестируется на встроенной графике AMD Radeon).

- [x] Инициализация Instance, Physical & Logical Devices
- [x] Настройка Swap Chain и Image Views
- [x] Render Pass и Framebuffers
- [x] Компиляция и загрузка SPIR-V шейдеров (`vert.spv`, `frag.spv`)
- [x] Настройка Graphics Pipeline (включая Alpha Blending для полупрозрачных UI-элементов)
- [x] Command Pools & Buffers
- [x] Объекты синхронизации (Semaphores, Fences) для управления кадрами
- [ ] Отрисовка первого треугольника / 3D-геометрии (Next Step)

## 💻 Разработка
Проект разрабатывается и собирается в CLion (Lenovo T14s). Архитектура движка модульная и с самого начала проектируется с учетом работы на интегрированных видеокартах для максимальной доступности.
